# #205 Tách kiện trong app (PR 1): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kho tách một kiện `reserved`/`backordered` thành nhiều kiện qua `POST /fulfillment/packages/:id/split` (Lazada, đơn tay chia trong app; TikTok gọi sàn tách trước), lượt kéo đơn giữ nguyên cách chia của app, và CSDL chặn một dòng đơn bị nhân đôi trên các kiện.

**Architecture:** Luật chia thuần ở `domain/split.ts`. Service `service/split.ts` đi ba bước trong khoá phiên theo kiện: kiểm (giao dịch ngắn) → gọi sàn tách ngoài giao dịch (chỉ `splitLevel = 'sku'`) → xin mã kiện trong giao dịch riêng → ghi (khoá phân hàng → khoá kiện của đơn → chuyển dòng → phân hàng nếu kiện cũ `backordered`). Channel tiêm `splitLevel` qua `ctx.marketplacePackages`; sales tiêm `orderViewOf`, `nextPackageCode` qua `withContext`. `syncPlatformPackages` gom món chưa có mã kiện sàn theo kiện app đang chứa nó. Constraint trigger hoãn tới commit chặn tổng vượt số lượng dòng đơn.

**Tech Stack:** Node.js 24 (chạy thẳng `.ts`), Express 5, TypeScript 6, Zod 4, Drizzle ORM + PostgreSQL 18 (staging 17), Vitest + Testcontainers.

**Spec:** `docs/superpowers/specs/2026-11-14-205-tach-kien-design.md` (gọi tắt "spec"; D1–D15, mục 5.x, AC1–AC14, AC7a, AC7b). Plan này chỉ làm **PR 1** (spec mục 4); PR 2 (spec §5.10) có plan riêng sau khi PR 1 merge. Executor đọc spec trước task đầu tiên.
