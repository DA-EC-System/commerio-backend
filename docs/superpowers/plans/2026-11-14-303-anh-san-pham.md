# Ảnh sản phẩm ở catalog (#303) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Catalog lưu được tối đa 9 ảnh mỗi sản phẩm (ảnh đầu là ảnh đại diện), trả `images[]`/`thumbnailUrl` ở catalog và `ListingRow`, đẩy lên sàn tự lấy ảnh catalog; vé `product_image` chỉ nhận JPG/PNG ≤ 1 MB.

**Architecture:** `core/files` thêm hàm kiểm tệp tổng quát (`fileProblem`) và hàm dựng link công khai (`publicFileUrls`); catalog ghi bảng `product.product_images` có sẵn, gọi `files` qua `core/index.ts`, export `productImageUrls` cho module khác; channel đọc ảnh qua `ProductPort` lúc bấm đẩy rồi đặt vào `imageUrls` của việc `channel.listing_push` như hiện nay (worker không đổi). Migration (unique `(product_id, position)`, CHECK `position >= 0`) sinh ở task cuối.

**Tech Stack:** Node.js 24 (chạy thẳng `.ts`), TypeScript 6, Express 5, Zod 4.6, `@asteasolutions/zod-to-openapi` 9 (đọc `.meta()`), Drizzle ORM 0.45 + PostgreSQL 18, Vitest 5 + Supertest.

**Spec:** `docs/superpowers/specs/2026-11-14-303-anh-san-pham-design.md` (đã duyệt 14/11/2026). Đọc spec trước task đầu tiên.
